首轮发现桌面引导标题意外折成三行，已通过明确分行和字号修正；窄屏封面初版文字太小，已改成图上字下并增大标题。测试脚本曾因执行超时、控件完整名称和导出回调等待不足中断；核对实际页面状态后分段复核，报告只采用成功的检查结果和实际落盘文件。导出提示不能代替下载文件校验。

所有有状态浏览器测试仅使用独立端口的 loopback 源 `http://127.0.0.1:49831`。没有向用户的离线或线上存档写入测试作品。截图来自 Tabbit / Chromium；小屏幕为尺寸模拟，实体手机、其他浏览器与用户审美认可尚未验证。

结构化结果见 `浏览器验收.json`；桌面、平板、窄屏、书架、沉浸截图及实际明信片均在本目录。原始工具回执已被 Git 忽略。
