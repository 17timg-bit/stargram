# v1.7.0「回声手稿」本地验收

日期：2026-10-28。开发基于已发布 v1.6 的 `27eab79`，位于 `feature/v1.7-echo-manuscript`。本版仅制作本地提交与 `v1.7.0` 标签，没有推送、修改远程仓库或部署网页。

## 最终变化

- 织星台首次打开，完整复制当前选中轨道；原轨与手稿分开保存。
- 十行星谱纸按实际发声顺序显示，可指针或键盘改音高、轻重；原轨为空心标记，手稿为实心星星。
- 独立60步撤回/重做，以及清空、恢复原轨、改周期、旋转。
- A/B 使用各自周期试听原轨和手稿；编辑、关窗与停止取消旧异步结果，结束后释放节点。
- 生成器保留为折叠区域，只在按“织出候选”后替换手稿。
- 页面内最近12份手稿暂存；应用只替换一轨，可在主界面一次撤销。刷新或换整张星图结束暂存，不增加持久存储键。
- 原有宇宙暗房、音乐格式、收藏格式、主音频模型和合成器沿用。

- PNG：1600×1200，所有分块CRC通过，已查看；配方码SG1-4423。
- 两个根目录HTML入口字节相同：**183871字节**，SHA-256 `1bbe872763ad6cd01efcff4fc1d4af5d8996701c104dfc87680d43131d129d86`。

v1.1和v1.3旧样片另用原校验器的 `--report` 复核通过，结果写在本版目录，历史报告及样片未修改。

## 制作中修正与验证边界

A/B移动至左侧预览卡顶部，避免初稿在短窗口中被底部按钮遮住；试听A时同步切换左侧音符序列、星数与周期，避免原轨环谱搭配手稿信息。后续排版和音频检查基于这些修正完成。

浏览器验收脚本出现过折叠区域被重复关闭、书架按钮名称匹配歧义，已只读核对现场后修正测试定位再执行；没有把失败或半途执行计为通过。读取下载API不可用时，改从实际下载目录按准确文件名核验文件。浏览器片段使用顶层await，不能按CommonJS普通Node脚本执行。

这是Windows浏览器实测与尺寸模拟；实体手机触控、完整屏幕阅读器体验、真实后台切页取消未在本版重新人工验收。技术校验也不替代旋律听感与视觉喜好的试玩反馈。

全部写入只发生于独立49922源，未操作用户文件入口或公开网页的存储。测试标签已关闭、Tabbit任务正常结束、本地HTTP服务已停止。临时截图与诊断JSON不加入Git；整理后的源码、脚本、样片、截图和报告随本地版本保留。
