# v1.5「光影之间」本地验收

日期：2026-10-28。从本地 `v1.4.0` 继续，分支 `design/v1.5-light-and-shadow`。本轮仅保存本地版本，不上传 GitHub，不部署。

## 结果

- 左下角说明、声部快捷键与星数改为同一正常流页脚；声部列表单独占据 Grid 行，不再各自绝对定位叠加。
- 唱臂暂停时停在唱片外，主曲播放时平滑落针，暂停后回座；有停靠座、配重、唱头和针尖。候选试听不改变主唱臂位置，运行中修改减少动画偏好也生效。
- 三套完整主题：纸间晴昼、鎏金夜航、雾蓝回声。控件、弹窗、唱片、书架小唱片、织星谱和 PNG 封面共用配色；外观独立记住，原“星空色彩”改称“星图调性”。
- 音乐核心、音频引擎、收藏模型和织星模型源码没有改动。旧星图、收藏和音乐格式保持原规则。

## 已验证

- 23 项模型测试全部通过，`node --check src/app.js`、`git diff --check` 通过。
- 两个入口字节一致，142734 字节，SHA256：`f5776386a90d1366c76b3d95388caef4e2d4704fa4f4d509af73fd8ab391223e`。
- 10 组浏览器检查通过，最终脚本错误 0。涵盖主题重载记忆、播放中切换、主曲与收藏不变、唱臂中间态及两端位置、运行中减少动画、桌面/手机真实指针与撤销、夜间收藏和织星试听应用撤销、外观存储失败与非法值回退。
- 三主题 × 11 种尺寸共 33 组布局检查通过：2189×1235、1920×1080、1460×823、1440×960、1280×720、1200×800、1000×900、800×900、700×844、390×844、320×700。无横向溢出；声部列表、页脚文字分离；底座全部六项控制可见；撤销和拍照可滚动到达。
- 另外检查桌面页脚提示、快捷键与操作按钮未落在圆盘上；手机主题弹窗没有横向溢出。跨断点验收先等待 Canvas 尺寸匹配，同时监听过渡中的错误。修复了过渡几何下圆标内圈的负半径异常，并重跑最终检查。
- 正文、次级文字、输入框和播放按钮的前景/背景对比均至少 4.5:1；这只是指定颜色对的检查，不是完整无障碍审核。
- 三主题共六份实际下载 PNG 均完整、1600×1200、CRC 正常；每个主题的普通/沉浸导出逐字节一致，左上角像素分别对应暖白、深墨与雾蓝背景。实际 PNG 和哈希在 `浏览器验收.json` 中。
- 既有 v1.1 / v1.3 示例复核通过：WAV 无削波，MIDI 70 / 79 个音的音高、时间和力度吻合。未重新编曲，复核结果写入本版本目录，未覆盖历史证据。
