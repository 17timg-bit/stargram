# v1.4「星际唱片室」本地验收

日期：2026-10-28。基于已发布主线 `3c8aa2e`，本地分支 `design/v1.4-orbital-records`，版本标签 `v1.4.0`。本轮没有上传 GitHub 或部署，公开网站继续使用 v1.3。

## 本次改变

主界面从夜色三栏改成暖白纸面的唱片室：大号开场标题、墨绿胶片与唱纹、纸质圆标和唱臂、唱片旁的声部选择、独立调音区、彩色预设封套、常驻演奏底座。全部对话框和书架采用同一套装帧，导出柜台增加 PNG 卡片，明信片也改用唱片构图。

保存提示从设置滚动区域中分离，桌面保持可见；手机保留速度、音阶、回响、音量、播放和从头演奏。织星台保留现有生成机制，明确写出“新候选”，没有加入原稿编辑或草稿记忆。

音乐核心、音频引擎、书架和织星模型源码未改。没有更换存档键或星图 v2 格式，v1 导入继续支持。
