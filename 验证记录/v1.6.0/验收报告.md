# v1.6「宇宙暗房」本地验收

日期：2026-10-28。从 `v1.5.0` 本地版本继续，分支 `design/v1.6-cosmic-darkroom`。本轮不推送 GitHub，不部署。

## 本次改变

六天幕 × 五光谱 × 四星盘 × 三字样，合计 360 种配方。天幕有不同的程序纹理与形态，光谱同步影响控件、唱片与金属，星盘更换装饰结构，字体更换标题与题签。暗房实时预览当前星图，提供独立撤销、回到进来时、随机混合、六份起始配方和 SG1 编号复制/读入。PNG 封面也印上编号。

外观模型单独保存，读取迁移旧版三种主题并保留旧键；音乐核心、音频引擎、收藏模型、织星模型均未修改。天文意象经程序艺术演绎，资料与设计边界见 `docs/v1.6宇宙暗房.md`。

## 修正与证据边界

最初的整批浏览器矩阵触及工具 180 秒硬时限，未计入验收。按恢复说明重新接回原独立测试页、只读核对状态后，改成六个成功批次并保存完整结果。没有换用用户文件入口，也没有把半途执行当成完成。

弹窗滚动条、字体或尺寸变化会重置 Canvas 位图；旧路径等下一动画帧补画，曾捕获到透明画面。现为 ResizeObserver 与材料切换时立即补画，避免主唱片短暂消失；暗房打开与材料变化时也立即刷新样片。最终尺寸矩阵检查了真实位图，不仅检查 CSS 边界。

所有有状态操作仅在独立 `http://127.0.0.1:49921` 源。没有写用户离线或公开网站的作品存储。手机为桌面 Chromium 尺寸模拟，尚无实体设备测试；审美仍由用户试玩判断。主界面、暗房、字体、星盘、手机与实际封面已归档并查看主要画面。

结构化结果见 `浏览器验收.json`，设计与来源见 `docs/v1.6宇宙暗房.md`。本轮保留本地 Git 版本，不上传或部署。
