日期：2026-10-27。状态：仅本地制作与 Git 留档，未上传、未部署。

## 结果

- 17 组模型测试通过，0 失败：原来的 9 组与新增的 8 组。包含 v1 迁移后事件 / MIDI 不变，力度与独奏，MIDI velocity 上限，24 张书架边界，深拷贝、重复、移除恢复、配额失败与损坏数据保护。
- 11 组交互、音频和窗口行为检查通过；另完成 2 组隔离后的导入、拖动与键盘回归。各阶段记录的页面错误均为 0。
- 实际浏览器操作覆盖命名、两种编辑方式、轻重音、分轨音量、多轨独奏、撤销 / 重做、收藏与去重、删除后恢复、收藏重载、沉浸与 Esc、节拍显示和暂停清音。
- 1440、1100、800、390 四种窗口宽度无水平溢出及舞台 / 底部控制栏重叠；小屏幕的随机与书架按钮同排，书架对话框可用。尺寸模拟不代表实体手机验收。
- 新旧两个根目录 HTML 入口字节一致，仍无需外部资源。最终文件长度与哈希见 `产物校验.json`。

## 本轮出现的问题与处理

1. MIDI 压力测试的初版独立解析器在 `p += vlq()` 中丢失了读取长度时对指针的增量。拆为先读长度、后推进指针；确认是测试解析器问题，产品 MIDI 的 127 上限与事件配对通过。
2. 把两次离线音频渲染误设为必须逐字节相同。实测差异只有 1 个 PCM16 单位，调整为允许该量化舍入误差，同时保留事件与 MIDI 的精确一致检查。
3. 小屏幕两个新按钮因行内空白而换行，改为明确的 Flex 容器，并在 390 像素回归中验证同排。
4. **存档事故：**复制的本地 HTML 测试入口与真正离线入口共享浏览器存储。测试替换了当前自动存档；测试连接重置后，只保存在运行时变量里的原状态备份丢失，未能恢复验收前状态。本轮未能恢复原自动存档，不能将当前演示状态称为原状态。当前浏览器保留两张演示收藏，项目内原有文件、旧示例均保留。最后两组回归改用 `127.0.0.1:49741` 独立源，避免继续影响文件入口存储；项目约定已要求后续使用隔离源或持久、受忽略的临时备份。
