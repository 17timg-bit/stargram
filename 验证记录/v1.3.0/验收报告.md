# v1.3「织星台」本地验收

日期：2026-10-27。基于已发布主线 `cfc9707` 继续开发，本地分支 `feature/v1.3-star-loom`，版本标签 `v1.3.0`。本轮没有推送 GitHub 或部署，公开网站继续使用 v1.2。

## 完成内容

新增单轨织星创作台：8 / 12 / 16 / 20 / 24 格周期、1 到满格的均匀密度、回旋 / 升起 / 落下 / 漫游、两个音区、呼吸轻重、相位错开、换种子、暖纸环形谱和文字音符序列。草稿可试听一圈及余音；关闭不写原星图，应用是一次可撤销操作。

试听使用原有 WAV 渲染引擎和音色，仅启用草稿轨道，保留音量、速度与回响。异步工作通过令牌取消，关闭或改动后不重启旧结果。主星图和书架格式保持 v2，仍兼容导入 v1。音乐核心、音频合成和书架存储源码未改。

- `node --test tests/core.test.js tests/v1.1.test.js tests/v1.3.test.js`：23 项通过、失败 0。新增 6 项涵盖全部 80 种合法周期/密度、960 组走向/音区/种子、参数边界、确定性、相位和试听隔离；原有迁移、MIDI、书架失败保护与无网络依赖检查继续通过。
- `node --check src/app.js`：通过。两份构建 HTML 字节一致，129111 字节；SHA256 为 `b2f24ccb619ab517c5ae615c7dfcd8c5aef6baf9806e066ff8be290a26ff2916`。
- 7 组浏览器检查通过：草稿改变与关闭不改原星图；短周期会夹紧密度上限；应用只改当前轨道；一次撤销、重做与刷新恢复正确；打开创作台暂停主曲并清空已有声音；试听停止和自然结束释放节点；播放时改草稿立即停止旧音；收藏、导入、导出与重载继续可用。
- 用可控异步门等待渲染完成，确认“关闭准备中的试听，再让旧渲染返回”不会产生迟来的声音；不是靠固定延时猜测结果。8 格试听自然结束后 BufferSource 节点数为 0，Esc 关闭正常。
- 试听传入的完整星图快照与手动隔离当前草稿的参考快照完全一致。两次独立 Web Audio 渲染字节长度相同，PCM16 最大差 **1 个单位**，差异 RMS 为 **0.00305 个单位**；未宣称逐字节相同。验证副本在 `decodeAudioData` 前复制，避免原 ArrayBuffer 被转移后无法读取。
- 1440×900、1200×800、800×900、390×844、320×700 模拟尺寸下，弹窗无横向溢出，应用按钮可通过弹窗滚动到达；背景滚动锁定，Esc 与减少动画样式正常。桌面和窄屏截图已查看。

## 边界与记录

所有有状态验收仅在独立源 `http://127.0.0.1:49857` 运行，没有向用户的离线或公开网站存档写入测试作品。浏览器测试中途发生任务运行时重连，核对原测试标签后接回同一个独立源；已完成结果保存在文件中，没有依赖运行时变量备份用户存档。

真实切换到后台的检查被 Tabbit 的前台保持策略阻止，当前 CLI 也未接受错误提示中的前台选项，因此没有声称这一项实测通过。页面隐藏调用相同取消函数的处理已实现；手动停止、参数改变、关闭、取消异步准备和自然结束均有真实操作验证。

窄屏是浏览器尺寸模拟，未在实体手机上验收。音色和音乐审美需要用户试听认可，客观文件校验不替代听感判断。结构化结果见 `浏览器验收.json`、`产物校验.json`；桌面、窄屏与工作台图片在本目录，示例与重建脚本已归档。
