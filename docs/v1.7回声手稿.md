# v1.7「回声手稿」

这次想让一张已经喜欢的星图，能够被认真地续写。宇宙暗房让作品有了自己的外观，回声手稿则给旋律留下一张可以反复推敲的纸。

## 从现有声音起笔

织星台刚打开时，手稿与当前选中轨道完全相同，包括周期、相位、音符和力度。进入窗口不生成随机旋律；“原轨副本”是明确的起点。

左侧仍是一圈星轨，右侧变成星谱纸。横向按实际发声顺序排列，纵向由高到低列出十个音。轨道数组中 `shift` 之前的存储顺序不会暴露给使用者：第 1 格就是从头演奏时的第一格。每列只保留一个音，与这件乐器原有的单声部轨道相同。

同周期时，空心圆保留原轨的位置，实心星星显示手稿；改写以后，还能看到自己离起点有多远。改周期时，原位置不再适合直接叠画，所以改为显示周期前后值，并保留 A/B 试听。周期映射沿用主界面的规则，缩短时可能合并相邻音符，可以撤回。

## 手稿与偶然并存

“织一个新念头”收在星谱纸下方。疏密、走向、音区和呼吸是下一次生成的选项，按“织出候选”才会替换手稿。这样，刚写好的几个音不会被一次滑动悄悄覆盖。生成结果也是编辑历史中的一步，可以拿来继续写，也可以撤回。

手稿具有独立的最近 60 步历史；清空、抄回原轨、旋转、改周期和生成候选都在其中。应用把整个手稿作为主星图的一次修改，只改变当前轨道，保留原轨增益、静音与独奏设置。

## 听过，再留下

A 试听进入时的原轨，B 试听当前手稿。每段都用自己的周期，沿用主星图的音阶、速度、轨道音色、分轨音量、总音量和回响，暂时绕过静音与独奏，确保是在比较同一个声部。总音量或该轨增益为零时不给出无声的试听按钮。

两边共用一个试听控制器；切换会结束上一段。手稿编辑、生成选项变化、关窗、停止或页面隐藏均取消旧任务。准备 WAV 和解码是异步的，每个阶段都检查取消令牌，避免关窗后准备完成又突然出声。试听用与导出相同的音频引擎，结束后释放节点；主唱针由主播放状态控制。

左侧环谱、音符序列、数量和周期随着正在试听的 A/B 对象一起切换；星谱纸始终保留可编辑的 B 手稿，A 播放时不把原轨的游标投到手稿上。

## 暂存的边界

关窗会保留本次页面的手稿；同一声部、同一原轨内容重新打开，就能继续写，并接回独立历史。页面最多暂存最近 12 份，不写入新的浏览器存储键。更改整个星图、刷新页面会结束暂存；应用后清掉该声部的旧手稿。音阶、速度和回响是试听环境，再次打开时读取当前值。

它不是另一个作品库。要长期留下旋律，应应用到轨道，再用原有自动存档、收藏或 JSON 导出。窗口内把这条边界写在按钮旁。

## 排版与输入

星谱纸沿用当前宇宙暗房的色彩和字体；纸面刻度、空心原稿与轻重音使用 CSS 绘制，没有新增图源或字体依赖。长周期在纸内滚动。窄屏把 A/B 操作留在纸前，收起重复的环形预览，减少操作距离。应用按钮在窗口底部，并检查其不遮住最后几项编辑操作。

键盘只需一次 Tab 进入星谱纸，再用方向键、Home、End 定位，Enter 或 Space 写入；撤回和重做快捷键只在星谱内接管。ARIA 网格给每个位置标明格子、音高和当前状态。实体手机触控与屏幕阅读器仍需专门人工验收，本次浏览器尺寸检查不等同于这些体验。

## 验证资料

`tests/v1.7.test.js` 验证纯模型与缓存边界。`tests/v1.7-browser-*.js` 为 Tabbit 浏览器片段，使用独立 loopback 源，避免改动本地文件版或已发布版的作品。实际截图、A/B 渲染比较、尺寸矩阵和导出校验见 `验证记录/v1.7.0/`。

本地样片从界面改写并导出，保持现有 v2 星图、WAV 与 Type 1 MIDI 格式；`scripts/verify_v17.py` 独立解析声音与事件。技术检查验证一致性与可交付性，旋律和视觉是否喜欢仍留给实际试玩。
