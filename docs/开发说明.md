# 开发说明

## 源码分层

| 文件 | 职责 |
| --- | --- |
| `src/index.html` | 语义化界面、原生对话框和表单 |
| `src/style.css` | 桌面、窄屏和减少动画偏好 |
| `src/core.js` | 无 DOM 的确定性模型、预设、校验、音阶、事件和 MIDI 编码 |
| `src/audio.js` | Web Audio 合成、音频时钟调度、混响、压缩和离线 WAV 渲染 |
| `src/app.js` | Canvas 绘制、指针操作、历史记录、存储和文件交互 |
| `scripts/build.js` | 把源码内联为单文件 HTML |

`src/index.html` 是构建模板；请打开根目录构建后的 HTML。使用经典内联脚本避免 `file://` 下 ES module 或资源加载的限制。

## 时钟与声音

播放使用 AudioContext 时钟；25 ms 调度器预排约 100 ms 音符，画面根据同一时钟定位彗星，光圈到真实预定发声时间才产生。动画帧不承担发声调度。后台标签页会暂停；返回前台不自动播放。

半拍时长为 `30 / BPM` 秒。轨道的音符索引为 `(tick - shift) mod length`，对应的视觉位置为 `(index + shift) / length` 圈。拖动到已占用位置交换音符，避免悄悄删除目标内容。

合成器采用正弦谐波叠加、短起音和指数衰减；每条轨道固定声像。干声与由固定随机种子生成的卷积混响汇入压缩器与音量节点。音频节点在结束时断开连接；暂停和重置时取消已有发声节点的调度。WAV 离线渲染采用相同的音色和混音图，编码前检查峰值，超过 0.88 时整体降低电平再写入 PCM16。

MIDI 使用 Type 1、480 PPQ。速度与拍号在独立 conductor 轨；五条乐器轨保留 ASCII 名称、GM 音色提示和均衡的 note-on / note-off。MIDI 不传递此应用的混响脉冲和合成器。

## 存档契约

格式名 `stargram`、版本 `1`；最多 5 条固定轨道。每轨长度只接受 8/12/16/20/24，音符数组长度须严格匹配，元素为 -1（空）或 0–9。所有音量、周期、音阶、速度和偏移必须经过校验；导入文件上限 100 KB。未知字段丢弃，标题用 `textContent` 显示，不插入 HTML。

本地存储键：`stargram.universe.v1` 和 `stargram.discoveries.v1`。存档损坏或存储不可用时回退到预设，并给出提示；可用 JSON 文件保留作品。

## 验证

`node --test tests/core.test.js` 检查真实边界：周期/旋转、静音、音阶、1000 个确定性随机编排、非法导入、MIDI 事件配对与单文件离线依赖。

`python scripts/verify_artifacts.py` 独立读取实际交付 WAV、MIDI、JSON 和 PNG，核对编码、时长、峰值、音符对应及文件哈希。

`tests/browser-*.js` 是供 Tabbit 技能通过 CLI 执行的原生 Playwright 验收片段，不是普通 Node.js 脚本。它们有明确执行顺序及共享 `qa` 状态：先 open，再 check、drag，随后按需执行 export、layout、import。脚本中的本机路径需随项目迁移调整。浏览器导出会在浏览器下载目录产生实际文件，运行前应留意同名下载编号。

本次验证的具体结果、已修正问题和证据边界见 `验证记录/验收报告.md`。没有部署在线服务，也没有安装全局依赖。
