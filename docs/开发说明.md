# 开发说明

## 源码分层

| 文件 | 职责 |
| --- | --- |
| `src/index.html` | 语义化界面、原生对话框和表单 |
| `src/style.css` | 桌面、窄屏和减少动画偏好 |
| `src/core.js` | 无 DOM 的确定性模型、预设、校验、音阶、事件和 MIDI 编码 |
| `src/audio.js` | Web Audio 合成、音频时钟调度、混响、压缩和离线 WAV 渲染 |
| `src/shelf.js` | 24 张独立收藏、重复快照识别、存储事务、移除与恢复 |
| `src/loom.js` | 确定性的织星草稿、均匀密度、旋律走向、独立试听快照 |
| `src/app.js` | Canvas 绘制、指针操作、历史记录、存储和文件交互 |
| `scripts/build.js` | 把源码内联为单文件 HTML |

`src/index.html` 是构建模板；请打开根目录构建后的 HTML。构建会同时输出字节一致的 `index.html`（网页入口）与 `打开星轨留声机.html`（离线入口）。使用经典内联脚本避免 `file://` 下 ES module 或资源加载的限制。

## 时钟与声音

播放使用 AudioContext 时钟；25 ms 调度器预排约 100 ms 音符，画面根据同一时钟定位彗星，光圈到真实预定发声时间才产生。动画帧不承担发声调度。后台标签页会暂停；返回前台不自动播放。

半拍时长为 `30 / BPM` 秒。轨道的音符索引为 `(tick - shift) mod length`，对应的视觉位置为 `(index + shift) / length` 圈。拖动到已占用位置交换音符，避免悄悄删除目标内容。

合成器采用正弦谐波叠加、短起音和指数衰减；每条轨道固定声像。干声与由固定随机种子生成的卷积混响汇入压缩器与音量节点。音频节点在结束时断开连接；暂停和重置时取消已有发声节点的调度。WAV 离线渲染采用相同的音色和混音图，编码前检查峰值，超过 0.88 时整体降低电平再写入 PCM16。

MIDI 使用 Type 1、480 PPQ。速度与拍号在独立 conductor 轨；五条乐器轨保留 ASCII 名称、GM 音色提示和均衡的 note-on / note-off。力度为分轨增益乘单音力度，再映射至 MIDI velocity（钳制为 1–127）。独奏与静音与现场一致。MIDI 不传递此应用的混响脉冲和合成器。

## 存档契约

格式名 `stargram`，新导出版本 `2`；5 条固定轨道。每轨长度只接受 8/12/16/20/24，音符数组长度须严格匹配，元素为 -1（空）或 0–9。`accents` 与音符等长，只接受 0.55 / 1 / 1.35；`solo` 为布尔值。所有音量、周期、音阶、速度和偏移必须经过校验；导入文件上限 100 KB。未知字段丢弃，标题用 `textContent` 显示，不插入 HTML。

兼容读入 v1：缺少 `accents` 时补 1，缺少 `solo` 时补 false，原有事件增益与 MIDI 保持不变；读入后统一得到 v2 对象。v2 必须包含完整表达字段，避免导出或分享时静默丢失设置。

本地存储键：`stargram.universe.v1` 和 `stargram.discoveries.v1`。存档损坏或存储不可用时回退到预设，并给出提示；可用 JSON 文件保留作品。

书架独立使用 `stargram.collection.v1`，条目包含随机 ID、时间戳和完整星图快照，最多 24 张；读入会验证和迁移星图。存储失败时保留原内存和落盘数据，损坏数据不会被新收藏覆盖。重复快照不额外占用空间，移除保留最近一次恢复入口。收藏不是云端备份。

混音图新增五路轨道增益节点：轨道音量在节点上变化，音符的轻重由包络承担，避免把分轨音量重复乘两次。静音与独奏会淡出已在发声的轨道。画面与导出都调用 `audible` / `eventsAt`，不各自推导音轨选择。

## 验证

`node --test tests/core.test.js` 检查真实边界：周期/旋转、静音、音阶、1000 个确定性随机编排、非法导入、MIDI 事件配对与单文件离线依赖。

`node --test tests/v1.1.test.js` 增加旧格式迁移、独奏优先级、力度、MIDI velocity 上限，以及书架容量、深拷贝、重复、移除恢复、配额失败和损坏数据保护。

`python scripts/verify_v11.py` 独立解析实际导出的新版 MIDI，对照星图核对音高、起音和 velocity，并检查实际 WAV 时长、编码与电平。结果存放 `验证记录/v1.1.0/`，保留 v1.0 的历史证据。

后续版本复核旧示例时传入 `--report 验证记录/v1.3.0/旧版示例复核.json`，避免覆盖旧版产物哈希。`node --test tests/v1.3.test.js` 覆盖织星草稿的全密度边界、确定性、相位、音区、力度和试听隔离；`python scripts/verify_v13.py` 核对 v1.3 实际示例 WAV / MIDI。完整浏览器片段使用独立测试源 `http://127.0.0.1:49857`，按 open、edit、audition、layout、final 运行，不能当普通 Node.js 脚本执行。

`python scripts/verify_artifacts.py` 独立读取实际交付 WAV、MIDI、JSON 和 PNG，核对编码、时长、峰值、音符对应及文件哈希。

`tests/browser-*.js` 是供 Tabbit 技能通过 CLI 执行的原生 Playwright 验收片段，不是普通 Node.js 脚本。它们有明确执行顺序及共享 `qa` 状态：先 open，再 check、drag，随后按需执行 export、layout、import。脚本中的本机路径需随项目迁移调整。浏览器导出会在浏览器下载目录产生实际文件，运行前应留意同名下载编号。

新版的 `tests/v1.1-browser-*.js` 应在独立本地 HTTP 源运行：先在项目目录启动 `python -m http.server 49741 --bind 127.0.0.1`，再执行 open、edit、audio、layout、final 片段，结束后关闭服务器。每次验收优先换用未使用过的端口，并同步修改片段地址。不要复制 HTML 后直接进行有写入的 file:// 验收；本机已实测文件入口会共享存储。详见本轮报告中的存档事故记录。

本机验证的具体结果、已修正问题和证据边界见 `验证记录/验收报告.md`。网页通过 GitHub Pages 发布，不需要应用后端或全局依赖。Pages 采用 `main` 分支根目录；`.gitattributes` 固定文本换行为 LF，确保跨平台检出后生成文件的哈希稳定。

`scripts/github_pages.py` 可用当前 Git 凭据管理器检查或配置本项目的 GitHub Pages；凭据只在进程内使用，不写入文件或打印。Git 上传通过 Git 自身的凭据管理器认证。

## v1.4 的纸面界面

`geometry()` 同时供主 Canvas 绘制和指针命中使用，桌面唱片偏右、手机居中、沉浸与 PNG 各有明确布局分支。不要对整个 Canvas 做 CSS 旋转；只旋转不参与编辑的中央圆标。固定演奏底座保留所有控制，右侧 `.inspector-body` 单独滚动，`.save-note` 留在其外。

`tests/v1.4-browser-*.js` 使用独立源 `http://127.0.0.1:49919`，按 open、edit、layout、surfaces、final 执行。最终 PNG 必须等真实下载完成后再校验；旧音频示例使用两个校验脚本的 `--report` 选项，把复核结果放进 v1.4.0 目录。

## v1.5 外观与唱臂

外观 token 定义在 style.css，app.js 在切换时缓存 Canvas 使用的色值。首屏小脚本只读取并检查 stargram.appearance.v1，外观失败不影响乐曲存档；主应用更新 theme-color 和可访问名称。唱臂插值跟随 engine.running，运行中的媒体偏好变化会更新 reducedMotion。

舞台采用 Grid 声部行及正常流页脚，手机几何读取 ResizeObserver 缓存的声部与页脚边界。快速跨断点时可能出现短暂的最小几何，装饰内圈半径须保持非负。浏览器脚本先等 Canvas 位图和 CSS 尺寸匹配再读边界，同时监听过渡中的错误。

本版浏览器片段按 v1.5-browser-open、appearance、layout、details、postcards 的顺序在独立 49920 源执行。它们通过 Tabbit nodejs 运行，不是普通 Node 测试；复用自建测试页，闲置重连后先核对并接回该页，不能接管用户的文件入口。最终结果、实际下载与截图位于验证记录/v1.5.0。

## v1.6 宇宙暗房

appearance.js 在 head 中先于样式执行，负责材料目录、可读色值、v1偏好迁移、v2配方存储与SG1编号协议。build.js 单独内嵌该模块，其余顺序为音乐模型/音频/书架/织星/天幕绘制/暗房控制/主界面。材料目录位次属于SG1协议，修改目录时应保持现有编号含义。

sky-paint.js 生成确定性1200×900纹理；切换天幕才更新纹理与页面底图。主场景、PNG和暗房样片复用该纹理与星盘绘制。暂停时样片按需刷新，演奏时预览限频；主Canvas在resize和换装时同步补画，避免背景标签页或弹窗滚动条变化后出现清空位图。

新增 tests/v1.6.test.js 枚举360组合及协议示例；浏览器片段使用独立49921源，并按天幕拆开尺寸矩阵。大矩阵触及Tabbit执行时限后不能把半途操作当成完成，先核对保留测试页，再保存每一批成功证据。使用原生剪贴板失败时提供选中编号的手动复制；没有网络上传、外部图源或字体下载。
