# v1.10「星句剪影」

## 这次继续做什么

v1.9补足了偶遇整曲的变化，当前应用已经有从随机出发、手写续改、收藏到寄出作品的完整路径。继续增加功能前，比较了三处缺口：

| 方向 | 价值 | 本次取舍 |
| --- | --- | --- |
| 整句旋律编辑 | 逐格改音已经可用，但把一句旋律升高、反转或接成回应需要重复点格子 | 本次完成，直接加深现有织星台 |
| 跨天保留手稿 | 关闭页面后可以继续未应用的想法 | 留作后续，需要独立处理来源变化、容量和恢复冲突 |
| 偶遇作品整理 | 连续探索时更方便比较与留存 | 留作后续，当前仍可使用撤销与书架收藏 |

想让织星台从“逐颗种星”走向“写一句，听一句，再回答一句”。这次没有增加新的页面或生成模式，而是在原有谱纸里加入可见的时间片段。

## 一道光带，一句旋律

打开织星台，点谱纸上方的格号作为起点，再点另一个格号作为终点，起终点都包含在选区里；从右往左点也可以。两侧有边线，选中的格号与整列谱纸共同着色。原轨空心标记仍留在谱纸上，手稿的实心星星使用当前宇宙配方的强调色。

下面的“星句剪影”会画出选中片段的实际旋律轮廓，星点大小表达力度，底部短线对应包含留白的每一格。这是选区内容的概览，音符之间的连线不是延音。信息条显示起止格、格数和星数。

织星台的应用栏也改为独立底栏，上方内容在自己的视口内滚动。原先的悬浮应用栏会在某些高度盖住第二排片段按钮；现在谱纸的可视范围与底栏各占自己的位置。

“圈选整轨”可操作一整圈；“取消圈选”只收起光带。选择和取消都不会改动音符、产生撤回记录或打断试听。再点一个格号就开始新的片段；Shift+点击格号可从当前起点延伸。聚焦音格后，按住Shift配合左右方向键、Home或End也能圈选；Ctrl/Cmd+A在谱纸内圈选整轨。

## 八种变换

| 操作 | 规则 |
| --- | --- |
| 升一音 / 降一音 | 按当前音阶升降一个音级，留白与力度不变。任何星星越过第1或第10音时，整次操作停住，不夹紧或绕回音高 |
| 反转音序 | 把片段的音符、力度和留白按时间倒序；不是反转声音波形 |
| 高低倒影 | 在片段自身最高音与最低音之间交换高低走向，节奏与力度保持原位 |
| 提前一格 / 推后一格 | 在选区内部循环错开一格，片段边缘的内容回到另一端；不会挤进邻句，也不改变整轨相位 |
| 接到后一句 | 把包含留白与力度的整段复制到后方同样长的留白。超出周期或目标中已有任意星星时整次停住，不覆盖或跨过末尾 |
| 擦掉这句 | 只清空选区，把选区的力度恢复到中力度；其他格子保留 |

空白片段、不会产生改变的对称变换，以及越界或被占用的操作会禁用。按钮提示说明原因；选区旁也明确说明循环错拍和接句条件。

所有变换按“实际听到的格子”计算，包括已有相位的轨道。片段外的原始音符与力度、轨道相位、音量、静音和独奏都保持原样。复制也不改变周期。

## 手稿与作品的关系

一次片段变换只占手稿历史中的一步，可以撤回、重做，再用A/B比较。变换会取消准备中或正在播放的原轨/手稿试听，旧结果不会重新发声。选择本身不打断正在听的那一圈。

关闭再打开同一条未改变的轨道，会接回本次页面中的手稿和编辑历史，选区重新从未圈选开始。周期变化时清除选区，避免后续操作指向已不存在的格子。刷新或换整张星图仍会结束页面手稿暂存。

按“把手稿种回这条轨道”才保存到主星图，主界面一次撤销可回到应用前。星图v2、旧v1导入、SL1信笺和SG1外观协议均沿用原含义。

## 交付范围

本版最初作为本地试玩交付，现已根据用户的发布要求公开上线。在线与离线入口使用同一份成品；单文件可以独立复制，新增轮廓与光带继续使用SVG、CSS和系统字体，没有网络依赖。

实际操作、尺寸模拟、导出文件及技术边界见`验证记录/v1.10.0/验收报告.md`。样片来自真实界面手写与变换，不把技术校验当作听感或审美认可。
