# v1.2「夜色观测室」

这次把星轨留声机做成一间小小的夜间观测室：一本可以拨动、收藏和演奏的星图册。五条轨道仍是视觉中心，周围的界面像观测仪器的刻度和唱片的装帧。

## 色彩与材质

以墨绿 `#091719` 和深青绿作底，薄荷色用于音符与操作反馈，黄铜色用于刻度、标题和播放键。暖纸色只集中在收藏标签和关键按钮上。背景颗粒由内嵌 SVG 生成，强度很低；不下载图片或字体。

中文标题使用系统宋体衬线栈，操作文字使用系统无衬线，英文小注和数字使用等宽字体。不同系统的实际字体会有差异。桌面引导标题明确分成两行，避免标点挤压造成意外换行。

## 操作布局

预设从字符图标改成三幅线描封面；五轨选择变成五枚并排按键，静音仍有独立按钮。编辑区按模式、周期、音符、音高与力度、分轨音量组织。播放键采用象牙色圆盘和细环，滑块统一材质。

宽屏保留三栏；中等屏幕将预设移到顶部；窄屏把三幅封面放在文字上方，舞台、设置、演奏控制纵向排列。短桌面窗口允许侧栏独立滚动，保证控件可达。保留键盘聚焦描边、语义按钮、原有快捷键和减少动画设置。

## 星空与收藏

Canvas 增加分段黄铜外环、渐变金属轨道、淡色平行细线和中心罗盘。星云与星点保持柔和，装饰没有改变可点击轨道的半径或音符位置。

收藏卡上半部保留深色星图，下半部改成暖纸标签，配收藏编号与宋体标题。明信片增加印刷式边框与标题；导出几何单独计算，避免是否开启沉浸视图影响导出的构图。

## 实现与边界

改动集中在 `src/style.css`、`src/index.html` 和 `src/app.js` 的绘制部分。音乐模型、音频合成、收藏存储实现未改。星图继续导出 v2，并兼容 v1；没有迁移或重置用户存档。

本地浏览器检查使用独立的 `http://127.0.0.1:49831` 测试源；没有在用户的离线页或公开网站原有存档中写入测试作品。窗口尺寸模拟不能代替实体手机测试，技术检查不能代替用户审美认可。美术版先保存在本地 Git 分支与标签；用户随后认可并授权公开发布，发布验证见 `验证记录/v1.2.0/公开发布.md`。
