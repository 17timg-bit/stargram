# 一小片宇宙，一首偶然的歌

我想做的不是一台需要先学会的软件，而是一件看一眼就想碰一下的小乐器。它应当有明确反馈：手指放下一点光，过一会儿，彗星回到那里，声音真的发生。

## 玩法

星图是一张圆形步进音序器。所有轨道共用半拍时钟，每条轨道有自己的循环长度。长度为 12 格与 16 格的两条轨道，分别每 6 拍和 8 拍回到起点，于是每隔 24 拍才同时回到起点。

这种交错让简单音型也会出现新组合。它是可预测的音乐规则，不是引力模拟，也不宣称每一次随机结果都有同等音乐性。

音阶限制让随手点出的音符更容易共处。三种音阶、五个音区与逐星音高，仍允许做出差异较大的片段。新编排保留当前音阶、速度和周期，再用短动机生成稀疏、有留白的星图。

## 视觉

底色接近深墨绿。五条轨道从内向外依次是暖铜、浅金、薄荷、雾蓝和淡紫；背景的测量刻度与虚线把它变成一件带仪器感的小物件。星星之间的淡线记录编排形成的几何形状，彗星尾迹表达时间，短暂扩散的光圈表达实际发声。

界面分为左侧星图收藏、中间舞台、右侧轨道编辑和底部演奏控制。手机宽度时改为上下排列。字体使用系统字体，避免离线时的字体依赖。

这里没有 AI 生成贴图。画面由原创 Canvas / SVG / CSS 几何构成；音色由本地合成产生。整个成品约几十 KB，运行时不联网。

## 取舍

- 不加任务压力，只用三条观测手记引导第一次探索。
- 不把保存绑定账号。自动保存方便继续玩，JSON 导出负责长期留存。
- 不引入外部乐库或大体积采样。声音为轻量合成音色，并不仿真钢琴或管弦乐。
- 不添加复杂音频工作站界面。需要继续编曲时，交给五轨 MIDI。
- 撤销保留最近 60 次修改，换预设、随机、清空、导入均可撤销。浏览器重新打开后不保留撤销历史。

这次交付验证了规则、交互、文件和本机音频生成；是否让人想长时间玩下去，仍需要真实使用者来判断。
