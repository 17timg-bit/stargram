# v1.5「光影之间」

这一版沿用唱片室的布局，处理真实窗口里的文字重叠，并把“这是一台正在演奏的唱机”落实到动作和主题上。先制作本地试玩，不上传或部署。

## 给文字一个真正的位置

旧版把声部快捷说明、舞台提示和星数分别绝对定位。窗口变矮时，五个声部加上快捷说明会进入另外两组文字的区域。现在声部列表作为舞台 Grid 中的一行，说明、快捷键、星数与撤销按钮进入同一正常流页脚；窄一点可以换行，手机则将声部条与页脚分成两行。

桌面仍保留大唱片，页脚左右两边的文字避开圆盘。手机的圆盘范围根据声部条和页脚的位置计算；绘制与真实指针命中继续共用几何函数。Canvas 标签内圈增加最小半径保护，避免跨断点的短暂布局状态产生负半径异常。

## 抬臂、落针、回座

暂停时唱臂停在盘外的支座，播放时围绕固定支点转入唱片。回座时反向平滑移动，支座始终留在原地；配重、金属高光、唱头与针尖有各自的细节。动画使用实际帧间隔插值，播放以音频引擎为准，没有为了动画延迟音乐。

开启“减少动画”时，唱臂直接到达对应位置；运行中改变该偏好也立即生效。织星台的单轨候选试听是另一个播放对象，主唱臂保持停靠。窄手机和沉浸界面继续把空间留给音符，不展示唱臂。

## 三间有不同光线的唱片室

| 外观 | 纸面与界面 | 唱片与金属 |
| --- | --- | --- |
| 纸间晴昼 | 暖白、森林绿、少量朱橙 | 墨绿胶片、浅纸圆标 |
| 鎏金夜航 | 深夜墨色、黄铜、琥珀 | 深绿黑胶、金色圆标与暖金属 |
| 雾蓝回声 | 冷雾蓝、银色、少量朱红 | 蓝色胶片、冰蓝圆标与银色唱臂 |

右上角的“换装”打开三张可预览的主题卡，手机改为横向小卡纵向排列。选择后窗口保持打开，方便比较；勾选、按钮名称与状态提示共同标记当前外观。弹窗、输入框、书架小唱片、织星谱和 PNG 导出一起换装，预设封套保留各自的插画身份。

主题色由 CSS token 定义，Canvas 在切换时读取并缓存，逐帧绘制不反复读取样式。外观使用独立存储键 `stargram.appearance.v1`，不进入星图、收藏、WAV 或 MIDI 的音乐数据。页面在样式加载前恢复合法主题，避免夜间主题重载时先闪白；非法值回到暖白。存储失败仍可换装，界面说明本次无法记住。

底座原来的“星空色彩”改称“星图调性”，明确它改变音阶，和外观选择各自独立。

## 验证

模型、旧格式和既有音频产物继续复核；本版另检查三个主题的记忆与失败分支、演奏中换装、唱臂进出、运行中减少动画、桌面/手机真实指针、候选试听与主唱臂隔离，以及三套实际 PNG 的普通/沉浸一致性。所有有状态测试仅在独立源 `http://127.0.0.1:49920` 中进行。

完整结果与界面截图位于 `验证记录/v1.5.0/`。手机为浏览器尺寸模拟，实体设备及用户审美反馈仍单独验收。
