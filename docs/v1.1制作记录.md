# v1.1.0「星图书架」

2026-10-27。开发在 `develop/v1.1-star-atlas` 分支完成，并以 `v1.1.0` 标签留档；制作阶段保留本地，随后按用户认可进入 GitHub Pages 发布流程。

## 这次想做的事

上一版提供了可以随手拨动的乐器，这一版希望让人更愿意留下自己的作品，并且有更细的表达空间。保留原来的星空气质，把收藏做成一排小小的观测卡片；音符强弱通过星芒和大小表达，演奏位置通过节拍文字与中心脉冲表达。

## 已制作

- 标题命名、24 张本地星图书架、独立快照、重复识别、移出与撤销。
- 种星 / 调音两种操作方式；已有星星的音高、轻中重力度与即时试听。
- 分轨音量与可叠加的独奏，静音优先。混音同时用于实时声音和文件导出。
- 撤销后的重做，含 Ctrl+Shift+Z / Ctrl+Y。
- 收起工作台的沉浸视图，Esc 返回。
- 音频时钟驱动的小节与节拍、相遇轨道名称、分音阶的淡星云与力度星芒。
- v2 星图格式，兼容读入 v1，并保留旧星图的原音符与电平。
- 两张书架演示星图、一段带轻重音的演示音频及对应 MIDI。

## 文件与验证

源码及生成入口保持原位置，老示例与老验证记录保留。新增资料分别位于 `示例作品/v1.1.0/` 与 `验证记录/v1.1.0/`。

具体测试结果见本轮验收报告。首次浏览器检查误把复制的文件入口当成存储隔离，覆盖了当前自动存档；中途测试会话重连，内存备份未能恢复。本地浏览器现在保留两张演示收藏，原有项目文件和旧示例没有改动。最终导入与拖动回归已切换至独立本地 HTTP 源，不再写入文件入口的存储；后续测试遵循项目 AGENTS.md 中的隔离与持久备份规则。

## 试玩顺序

1. 双击根目录离线入口，听一会儿自己熟悉的预设。
2. 选「浮光」并切到「调音」，点一颗已有星星，试试轻、中、重和不同音高。
3. 用分轨音量和独奏找自己想听清的声音；用撤销 / 重做来回比较。
4. 给作品命名，打开星图书架收藏。换个预设再从书架打开它。
5. 点「沉浸」安静听一会儿。喜欢的作品另存 JSON，就可以独立留存。

这一版的技术验收不代替实际听感和长期使用体验，下一步修改以试玩反馈为依据。
