# v1.4「星际唱片室」

这次以一家独立唱片室为完整视觉设定，把原来的夜色工作台改成纸面与实体唱片。变化覆盖主界面结构、Canvas、字号、配色、预设插画、固定控制底座、收藏陈列和全部对话框。

## 一张唱片，两个工作区域

暖白 `#f2efe6` 是纸面，墨绿 `#203f35` 是文字与唱片，朱橙 `#c8613b` 用于方向、编号和强调；薄荷、暖金保留原有声音的识别。页面开场使用大号宋体标题，操作用清楚的无衬线，唱片编号与边注用等宽字体，全部来自系统。

主界面改成唱片与调音室两栏。五轨选择移到唱片左侧，调音设置留在右边；三张预设封套和随机/收藏入口成为下方的唱片箱。演奏底座独立固定在视口底部，翻看预设、调音或书架时都可以控制声音。保存状态从设置滚动区域分离，始终可见。

手机上唱片居中，五轨成为唱片下方的选择条，调音与封套纵向展开；底座紧凑排成三行，保留全部音量、回响、音阶、速度、播放与重置控制。长页面通过滚动访问，不用把整套乐器挤进一张小屏幕。

## 把星轨刻进胶片

Canvas 外围由纸面、投影、墨绿胶片和细密唱纹组成；内层保留五轨音符、彗星和相遇反馈。中央圆标有 STARGRAM 字样、八向印记和唱片面标，演奏时仅圆标缓慢旋转，音符本身仍按各自周期运行。唱臂落在可编辑环之外，不改变星星的命中规则。

桌面把唱片向右移动，给左侧声部留下空间；手机与沉浸时回到中央。绘制、指针命中与拖动共用同一几何函数。明信片用独立几何参数，不跟随当前视口或沉浸排版。

三张封套是内嵌 SVG：橙色日轮与墨绿地平线、青绿潮汐与月亮、淡紫晶面与星点。书架缩略图也生成各自的彩色封套与小唱片，没有下载素材或外部字体。

## 全部窗口使用同一套装帧

命名、玩法、织星、书架和导出窗口改用纸面、细边框、墨绿按钮与朱橙编号。书架在宽屏三列陈列唱片；玩法使用较大的顺序号；导出柜台改为 WAV / MIDI / MAP / PNG 四块版面。PNG 新入口复用原有明信片逻辑。

织星台保持生成候选的玩法，并在窗口说明每次打开会产生新候选，应用前原轨道保持原样。这次改善表达，没有加入原稿编辑或草稿记忆。

## 实现边界

改动集中在 HTML、CSS 和 app.js 的绘制/界面逻辑。音乐核心、音频引擎、书架和织星模型未改；没有更换存档键或星图格式。构建仍输出两份完全一致、可以单独复制运行的 HTML。

本轮在独立本地 HTTP 源 `http://127.0.0.1:49919` 验收，避免接触用户文件页或线上作品。先保存本地 Git 版本，不上传或部署。技术检查、浏览器尺寸模拟与用户审美认可分别记录，详见版本验收报告。
