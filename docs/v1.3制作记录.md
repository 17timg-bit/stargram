# v1.3「织星台」

这轮把留声机从“逐颗种星”推进到“先织一小段旋律”。主界面沿用夜色观测室，只在轨道名字旁增加一个小入口；创作台像放在桌上的一张暖纸谱稿。

## 创作方式

每条轨道都能单独尝试星数、周期、四种旋律走向、五声音区、呼吸力度与相位。星星按 `floor(k × length / count)` 分散，循环相邻间距最多差一格；旋律与力度由固定种子确定。再织一次换种子，不改变当前星图。

`src/loom.js` 是无 DOM 的纯模型。草稿深拷贝原轨道，应用前独立于主星图；应用写入一次历史记录，保留该轨音量、静音、独奏，其余四轨不变。继续使用 v2 星图，不增加格式版本，原有 v1 导入继续可用。

## 一张可以读的环形谱

五条淡墨圆线表示低到高的五个音，角度表示相遇时机，实心点、外环与透明度表示力度。下方另列真实时间顺序的音符数字，避免只靠图形表达。深绿操作区与暖纸草稿形成材质对照，细金线和等宽小注延续 v1.2 的观测气质。

窄屏改为上下排列，缩小谱面并让弹窗内部滚动；弹窗打开时锁住背景滚动。保留原生模态焦点、Esc 关闭、清楚的键盘描边与减少动画偏好。

## 试听与生命周期

打开创作台会暂停主星图并清空已有发声。试听先把草稿装进独立快照，仅选中的轨道可听见，暂时绕过原静音和独奏；分轨音量、总音量、速度与混响保持原值。音量为零时给出说明，不偷偷调高。

试听复用 `OrbitAudio.renderWav`，渲染一圈和 3.2 秒尾音，再经当前 AudioContext 的 BufferSource 播放。没有额外采样、外部音源或网络请求。音频时钟驱动预览的读数，走完自然释放节点；手动停止、改参数、关闭或页面隐藏会取消旧试听。异步渲染使用递增令牌，关闭后才完成的旧结果会被丢弃；渲染工作串行，避免连续点击叠加准备任务。

## 示例与边界

「花园之外，还有星星」使用 8 / 12 / 20 / 16 / 24 格五轨、共 19 颗星。`scripts/create_v13_sample.js` 可以重建星图；WAV / MIDI 从实际应用导出，由 `scripts/verify_v13.py` 独立核对。它是演示片段，完整周期长于 8 小节，WAV 不保证无缝循环；音乐审美仍交给用户试听判断。
